Winnow Privacy Policy

Winnow collects nothing. No accounts, no analytics, no crash-reporting beacons, no advertising SDKs, no server of ours exists to collect anything with.

What the app does with your data

  • Keys never leave your device. Seed material is generated on-device and stored in the iOS Keychain (this-device-only, never synced).
  • No address leakage by default. The wallet learns its own transaction history by downloading compact block filters (BIP157/158) from random Bitcoin full-node peers and matching them on your device. The watch list is not sent to peers, but block requests, transaction relay and timing can reveal information. Direct peers see your IP. With opt-in Tor, onion peers use onion circuits and public clearnet peers see a Tor exit IP.
  • Mempool windows. While the Receive screen is open, the app subscribes to ordinary transaction-relay traffic and matches it locally — the same data every full node sees. Nothing about you is queried or revealed.
  • Broadcasting. Signed transactions are relayed directly to P2P peers.
  • Labels and explorer consent. A received payment can have a persistent local name without an address. Addresses supplied by you and explicitly selected local or explorer suggestions can be attached later. Funding-address suggestions remain unverified; they are not sender identities and reusing them can reduce privacy. Every explorer lookup requires consent explaining the transaction-ID disclosure and the current route. A sole result is never selected automatically. Opening an external browser gets a separate warning: it is outside Winnow’s Tor protection.
  • Opt-in Tor. Off by default. When on, wallet peer traffic, discovery, peer-list downloads and explorer lookups use the app’s embedded Arti proxy. Failure leaves Winnow offline without direct or system-DNS fallback. Switching modes cancels old requests and rebuilds connections. Backgrounding stops networking. Local/private destinations get no routing exception; I2P transport is not available.
  • Census refresh. Advanced settings downloads a public candidate catalog from census.winnowwallet.com only when requested. This request reveals network metadata to the service (a Tor exit IP when Tor is enabled), but contains no wallet address or transaction ID. Validation failure preserves good data. Refresh does not disconnect active peers; Reset and shuffle peers is a separate action that preserves manual settings and the downloaded catalog.
  • Third-party code. One dependency: libsecp256k1 (via the P256K Swift package). It makes no network calls.
